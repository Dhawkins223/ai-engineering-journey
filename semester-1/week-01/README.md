# Week 1 — Python + Git/GitHub

**Target:** 30 productive hours across six study days.

## Learning objectives

By the end of Week 1, be able to:

- Write small Python programs without copying a tutorial.
- Use variables and basic data types.
- Use `input()` and `print()`.
- Write and call functions with parameters and return values.
- Use `if`, `elif`, and `else` correctly.
- Use comparison and Boolean operators.
- Read and investigate a basic Python traceback.
- Explain Git versus GitHub.
- Use `git status`, `git add`, `git commit`, and `git push` independently.
- Push personally written code to GitHub and explain it line by line.

## Structure

- `exercises/` — small practice programs and course exercises
- `projects/` — Week 1 independent project work
- `notes/` — concise personal notes and reflections

## Week 1 project

Build a **Personal Budget Calculator v0.1** using input, numeric conversion, functions, calculations, conditionals, and formatted output.

Do not use AI to generate the complete solution. AI can be used to explain errors, concepts, and alternative approaches after attempting the work yourself.

## Completion gate

Week 1 is complete when all of the following are true:

1. A small Python program can be written independently.
2. Variables, types, functions, parameters, arguments, and return values can be explained.
3. Conditionals can be used correctly.
4. A basic Python error can be investigated.
5. Code can be added, committed, and pushed without a tutorial.
6. At least one personally written Python program exists in this repository and can be explained line by line.
